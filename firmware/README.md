# 펌웨어

밥통 제어기. **라즈베리파이 대신 ESP32** 를 쓴다.

```
ESP32-WROOM-32   Wi-Fi + BLE 내장 · 4MB 플래시 · 듀얼코어
```

파이보다 이 쪽이 제품에 맞다. SD 카드가 없어 손상될 일이 없고,
전원을 넣으면 2초에 뜨고, BLE 가 내장이라 목줄과 직접 통신한다.

**서버는 한 줄도 안 바뀐다.** 계약이 HTTP + JSON 이라 뭐가 붙든 상관없다.

---

## 핀 배정

ESP32-WROOM-32 는 쓸 수 있는 핀이 빠듯하다. 안전한 14개 중 12개를 쓴다.

| 슬롯 | STEP | DIR | EN | 카트리지 |
|---|---|---|---|---|
| 1 | GPIO4 | GPIO5 | GPIO13 | 오메가3 |
| 2 | GPIO14 | GPIO16 | GPIO17 | 피부장벽 |
| 3 | GPIO18 | GPIO19 | GPIO23 | 관절 |
| 4 | GPIO25 | GPIO26 | GPIO27 | 장건강 |

남는 핀: GPIO32, 33

### 쓰면 안 되는 핀

| 핀 | 이유 |
|---|---|
| 1, 3 | USB 시리얼 — 쓰면 업로드와 로그가 깨진다 |
| 6~11 | 내장 플래시 |
| 0, 2, 12, 15 | 부팅 때 상태를 읽는다. 출력으로 쓰면 부팅이 막힐 수 있다 |
| 34~39 | **입력 전용** — 출력이 안 된다 |
| 21, 22 | 로드셀 I2C 용으로 남겨둠 |

모듈에 **아예 없는** 번호: 20, 24, 28~31, 37, 38

### 전원

```
12V 어댑터 ──▶ 확장보드 초록 나사 단자 (VIN/GND)
ESP32 GND  ──▶ 드라이버 G 열            ← 공통 접지. 없으면 오동작
```

**ESP32 핀에는 절대 12V 를 넣지 않는다.**
DRV8825 는 3.3V 로직이라 레벨 시프터가 필요 없다.

## esp32_spin — 모터 진단

서버도 Wi-Fi 도 쓰지 않는다. **모터가 도는지만** 본다.
한 번에 다 붙이면 안 될 때 원인이 셋(배선·속도·네트워크)으로 늘어난다.

```
Arduino IDE → esp32_spin.ino 열기
Tools → Board  → ESP32 Dev Module
Tools → Port   → COM7
업로드 → 시리얼 모니터 115200
```

메뉴가 뜬다.

```
1  한 바퀴 (200 펄스)
2  반대 방향
3  20 펄스만
s  속도 바꾸기
a  모든 속도로 한 바퀴씩 — 어디서 도는지 찾기
t  EN 만 켜고 끄기 — 모터 잠김 확인
```

### 처음이면 `t` 부터

EN 을 내리면 **모터가 돌지 않아도 축이 뻑뻑해진다.** 전류가 흘러 코일이
자리를 잡기 때문이다. 손으로 돌려보면 바로 안다.

```
뻑뻑했다   전원·드라이버 정상 → STEP 신호만 보면 됨
차이 없다  12V · VREF · RESET/SLEEP 확인
```

원인을 반으로 줄이고 시작하는 셈이다.

### 그다음 `a`

느린 쪽(25Hz)부터 빠른 쪽(625Hz)까지 한 바퀴씩 돌린다.
**스텝모터는 가속 없이 빠르게 시작하면 안 돈다** — 어느 속도까지
도는지 눈으로 확인하고, 그 값을 배출 속도로 쓴다.

## 안 돌 때

순서대로 본다. 위쪽이 더 흔하다.

```
1. RESET·SLEEP 이 HIGH 인가      조립 안내서 05장
2. VREF 가 0.15V 인가            06장
3. 12V 어댑터가 켜져 있나
4. ESP32 GND 와 드라이버 GND 가 이어져 있나
5. 드라이버가 소켓에 거꾸로 꽂히지 않았나
```

**떨기만 한다면** 코일 쌍이 어긋난 것이다.
빨강·노랑이 한 쌍(1A·1B), 초록·갈색이 한 쌍(2A·2B).
